# Security policy

Report vulnerabilities privately to Gabriele Picco at
[piccogabriele@gmail.com](mailto:piccogabriele@gmail.com), with the subject
`agent-preflight security report`. Do not open a public issue with vulnerability details.

Include the affected version, operating system, expected and observed behavior,
and minimal reproduction steps using synthetic files. Never send real credentials,
private agent configs, or a working exploit. Coordinate disclosure with the maintainer
before publishing details. There is no guaranteed response deadline.

preflight is a pre-launch review tool,
not a sandbox or a complete security boundary. Its heuristics and config readers
are best-effort; see the README limitations.
