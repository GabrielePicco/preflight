# Changelog

## 0.1.0 — 2026-10-26

- Discover supported agent instructions and configs from the project up to HOME.
- Block wrapped launches until each discovered file's current hash is trusted.
- Show MCP servers, permission settings, provenance, and secret-looking filenames.
- Highlight suspicious instructions and report config changes around agent runs.
- Provide shell aliases for wrapped agent launches.
- Add macOS/Linux CI and binary packaging, with an optional Windows build.
- Use the Cargo package name `agent-preflight` and the CLI command `preflight`.
